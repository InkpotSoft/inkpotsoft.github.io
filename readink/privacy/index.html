readink by InkpotSoft

Privacy Policy

Effective date: October 2, 2026

Your books and reading data belong to you. This policy explains how readink, an EPUB reader for iPhone and iPad developed by InkpotSoft, handles information when you use the app.

1. Our approach

readink does not require an InkpotSoft account. We do not operate a server that receives your library, reading history, or server credentials from the app. The app does not include advertising, third-party behavioral analytics, or cross-app tracking. We do not sell your personal information.

Information may leave your device when you connect to a book server, enable iCloud synchronization, load external book resources, open external links, or choose to share information. These cases are explained below.

2. Books and reading data on your device

The app stores imported EPUB files, downloaded books, covers, book metadata, reading positions, bookmarks, annotations, reading sessions, search history, and preferences on your device as needed to provide reading, library management, search, and reading statistics. Temporary files and cached resources support imports, downloads, and rendering.

Importing a local book does not upload its file to InkpotSoft. Some publications may contain external resources or links. Loading such resources or opening a link can connect to the provider of that content, which may receive normal network request information.

3. Book server connections

If you add a Komga or Kavita server, readink connects directly to the server you specify to authenticate, browse libraries, retrieve metadata and covers, download books, and synchronize reading progress where supported. Requests may include your username, password or API key, account and book identifiers, and reading progress. The server operator can also receive connection information, such as your IP address.

Saved connection details and credentials are stored in Apple's Keychain. They are not sent to an InkpotSoft server. The operator of the server you choose controls its data handling and retention. Use a server you trust. HTTPS protects supported connections in transit; HTTP connections do not provide that protection.

4. iCloud synchronization

When the applicable synchronization setting is enabled and iCloud is available, readink uses Apple services to synchronize the following information:

  • Preferences: supported reading and library preferences use iCloud Key-Value Store.
  • Reading history: completed reading session records, including book identifiers, timing, device category, and reading statistics, together with associated book metadata such as titles, authors, covers, and library or source names, use CloudKit in your iCloud account.
  • Server connections: connection details, passwords, and API keys use iCloud Keychain when you enable server connection synchronization.

readink does not use these synchronization features to upload your EPUB files. Apple processes synchronized information under its Privacy Policy and service terms. InkpotSoft does not receive your Apple account password.

Turning a synchronization feature off stops that feature on the device and preserves local data. It does not, by itself, delete previously synchronized data from iCloud or other devices.

5. Diagnostics and information you share

readink records diagnostic logs on your device to help investigate errors. Logs can include operation names, timestamps, durations, error codes, application and device software information, and numerical diagnostic details. Values designated as private, including sensitive book or connection details, are redacted by the app's logging system.

Logs are eligible for automatic cleanup after seven days; cleanup runs during app use, so an expired file may remain until the next cleanup. You can adjust logging detail and clear saved logs in Settings → Logs. The file currently being recorded is retained.

Logs are not automatically uploaded to InkpotSoft. If you choose to share a log, the selected recipient or service receives that copy. Review a file before sharing it. Apple's optional system diagnostics and crash-reporting services are governed by your Apple settings and Apple's terms.

6. Permissions

You choose files for import using the system file picker. The app may request local network access to connect to a book server on your network. You can manage local network permission in iOS or iPadOS Settings. Disabling access may prevent related connections from working.

7. Retention and deletion

Local books, reading data, preferences, and connection records are kept until you remove them using an available app control or remove the app's local data. Temporary files and caches may be cleaned up automatically.

  • Use library management to delete imported books or remove downloaded copies. Removing a download does not delete the original book from its server.
  • Remove saved server connections through library settings. Removing a local connection does not necessarily remove a separately synchronized copy.
  • Use Settings → Logs to clear saved logs, subject to the current recording file described above.
  • Use Apple's available iCloud and account controls to manage cloud data, and contact your server operator to manage information retained by that server.

Deleting the app removes its local app container, but it does not necessarily remove Keychain records, iCloud data, device backups, data on your book server, or copies you have shared. InkpotSoft cannot directly delete data held solely on your devices or by your chosen providers.

8. Contact and privacy requests

For questions about this policy or readink's handling of information, contact InkpotSoft through the website repository's GitHub Issues. If you contact us, we use the information you provide to answer your request and keep it for as long as needed to handle that request and any applicable obligations.

GitHub Issues are public. Do not include personal information, passwords, API keys, server addresses, book files, or diagnostic logs in a public issue.

9. This policy website

This page is hosted on GitHub Pages. It contains no advertising, analytics scripts, external fonts, or embedded third-party media. GitHub states that it logs visitors' IP addresses for security purposes. Website hosting and GitHub Issues are subject to the GitHub Privacy Statement.

10. Changes

We may update this policy when readink's features or data handling change. The effective date identifies the current version. If a change requires additional notice or permission, we will provide it as required.
