Import an EPUB

  1. Save the EPUB file to Files on your iPhone or iPad. If it is in a ZIP archive, extract it first.
  2. Open readink and select Add Books in the empty local library, or use the plus button in the Library tab.
  3. Select your EPUB file, then open the imported book to start reading.

No readink account or book server is needed for local reading. Imported books can be read offline.

Make reading comfortable

Tap the reading area to show the reader controls. Use the appearance controls to adjust fonts, colors, and layout. You can also navigate chapters, search within a book, and save bookmarks. In supported text, select a passage to highlight it or add a note.

Common questions

A book will not import or open

Check that the file is an EPUB and has finished downloading in Files. Try another EPUB to see whether the issue is limited to one book. If it continues, contact us with the error message and the steps you tried.

A server will not connect

readink supports connections to your own Komga or Kavita server. Add a connection using Settings > Library > Add Server.

  • Check the server address, including its protocol, port, and base path when applicable.
  • Make sure the server is reachable from your device and that your sign-in details are valid.
  • For a server on your local network, allow readink's local network access in iOS or iPadOS Settings.

Will iCloud sync my EPUB files?

readink's iCloud features do not upload EPUB files. Completed reading sessions and server connection details can be synchronized through the options in Settings > iCloud Sync. Import local books separately on each device, or download them from your book server.

Where can I find diagnostic logs?

Open Settings > Logs in readink. Logs stay on your device unless you choose to share them. Review a log before sending it to us.
