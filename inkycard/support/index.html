Support

Help with dictionaries, pronunciation, and making Anki cards on your Mac.

InkyCard requires macOS 26 or later.

Contact InkpotSoft

Email inkpotsoft@icloud.com for help, bug reports, feature suggestions, or a request for the corresponding source code for your version.

Please include your InkyCard version, macOS version, what you expected to happen, and the steps that led to the problem. If relevant, include the dictionary name and the error message.

Remove private information from screenshots and attachments. Do not send passwords, API keys, or your entire Anki collection.

Start with a dictionary

  1. Open Settings > Dict.
  2. Choose Add Dictionaries... and select a Yomitan-format dictionary ZIP. Alternatively, choose Import Preset Dictionary... to download Jitendex or JMnedict.
  3. Enable the dictionary and arrange its priority, then type or paste a Japanese word or sentence in the lookup window. Select a matching word to see its entries.

Definitions, images, word frequency, and pitch accents depend on the dictionaries you import. Each dictionary has its own license.

Connect to Anki

  1. Install desktop Anki and the AnkiConnect add-on, then restart Anki and keep it open. See the AnkiConnect setup instructions.
  2. In InkyCard, open Settings > Anki and enable Anki integration. For Anki on the same Mac, the usual server address is http://127.0.0.1:8765. Enter an API key only if you configured one in AnkiConnect.
  3. Select a deck and the built-in note type, or select an existing note type and configure its field mapping. Choose Save.
  4. Look up a word and choose Add on the entry you want to study.

Anki integration is optional. If the connection fails, check that Anki is open, AnkiConnect is installed, and the server address and API key match its configuration. Save again after changing a deck, note type, or field mapping.

If an entry is reported as a duplicate, review the existing card before choosing to add another. Duplicate scope can be adjusted in Settings > Anki > Advanced.

Pronunciation and card audio

Open Settings > Audio, choose an available Japanese voice, and use the audio preview to check playback. The system audio source uses voices installed on your Mac.

To attach pronunciation audio to new Anki notes, enable Include Audio in Anki settings and save. If you use an existing note type, make sure its field mapping includes Audio.

History and dictionary backups

In Settings > History, choose how long to keep viewed words or use Clear History.... History stores the words you open, rather than every text you type.

Use Export... in dictionary settings to save a dictionary collection. Importing a collection replaces the current dictionaries after confirmation. Keep a backup before replacing a collection.
